## 一、引言

### 1.1 研究背景与意义

车牌识别是智能交通管理、停车场出入管理和道路视频分析中的基础任务。系统需要从完整场景图像中定位车牌位置，并将车牌区域转换为可用于检索、统计与业务处理的字符序列。实际采集条件与理想证件图像存在显著差异：摄像头往往位于车道侧上方，车辆相对镜头持续运动，车牌在图像中只占很小的区域；夜间照明、反光、雨雾与运动模糊会削弱字符边缘；侧向视角还会带来透视压缩与倾斜。因此，完整的车牌识别系统同时受到定位误差、几何畸变与字符辨识困难三方面的影响。

传统流程通常将车牌定位、字符切分与单字符分类依次执行。字符切分对二值化效果和字符间隔高度敏感，当字符粘连、倾斜或局部遮挡时，前一环节的错误会直接传递到后续分类器，造成错误累积。免分割序列识别通过直接预测整幅车牌的字符序列，减少了对显式字符边界的依赖，但并不意味着可以忽略输入图像的几何质量——若透视压缩使一侧字符过窄，或检测裁剪截断首尾字符，识别模型仍会输出缺字、错字或长度错误的结果。

本项目的核心研究切入点是 **空间变换网络（STN）矫正模块的系统性研究**：在"检测—矫正—识别"三阶段级联框架下，考察仿射变换与透视变换、定位网络结构、训练策略等设计维度对最终识别精度的影响，重点回答一个问题——**在哪些困难场景中，可学习的几何矫正能够带来稳定的识别收益**。

### 1.2 项目目标与主要工作

本项目构建面向中文单行车牌的识别系统，在公开数据集 CCPD2019 上完成检测、几何矫正、字符识别与端到端评估。总体技术路线为：

- **检测**：YOLOv8n 完成车牌定位，输出边界框与置信度；
- **矫正**：STN 对倾斜、旋转车牌进行可学习的几何矫正（支持仿射与透视两种模式）；
- **识别**：LPRNet 基于 CTC 损失实现免字符分割的端到端序列识别。

项目的主要工作与贡献如下：

1. **完整可复现的数据—模型—训练—评估—推理链路**：实现了 CCPD 文件名解析与清单生成、识别数据集、LPRNet 与 CTC 编解码、STN 矫正模块、端到端训练与统一评估脚本，全部 153 个单元测试通过。
2. **STN 变换类型消融（E1）**：对比无矫正（off）、仿射 STN、透视 STN 三种模式在基础集与倾斜/旋转挑战子集上的识别精度。
3. **发现并修复了 STN 的两个关键训练失效问题**：仿射模式的无约束塌缩（准确率 0%）与透视模式的回退死锁，提出**有界残差参数化**加以解决。
4. **揭示 STN 收益的数据依赖性质**：通过旋转数据增强重训实验，证明 STN 的矫正能力取决于训练数据的畸变分布，并在倾斜/旋转子集上取得统计显著（p<0.0001）的收益。
5. **数据扩充实验**：将识别训练数据从 2557 张扩充到 10000 张，识别整牌准确率由 92.68% 提升至 95.07%。

## 二、国内外研究现状

### 2.1 车牌检测

车牌检测本质上是特定类别的目标检测任务。以 YOLO（You Only Look Once）系列为代表的单阶段检测器[6]将目标定位与分类统一为回归问题，具有速度快、易于训练的特点，已成为车牌检测的主流选择。YOLOv8 是 Ultralytics 维护的较新版本[10]，采用无锚框（anchor-free）的解耦检测头与 C2f 模块，在精度与速度之间取得了良好平衡。轻量化的 YOLOv8n 参数少、推理快，适合作为课程项目与端侧部署的基线。本任务只设置一个"车牌"目标类别，字符类别交由后续识别器处理。

### 2.2 免分割序列识别与 CTC

车牌字符识别传统上依赖字符切分，对粘连、倾斜与光照敏感。免分割（segmentation-free）方法直接预测整幅车牌的字符序列，避免了显式字符边界标注。LPRNet[2]是代表性的轻量级车牌识别网络：以全卷积结构将二维车牌图像映射为沿水平方向排列的字符概率序列，配合 CTC（Connectionist Temporal Classification）[4]实现无需字符级对齐的序列监督。CTC 对所有能折叠为目标文本的逐帧路径概率求和，将字符边界的对齐问题"边缘化"掉，是本项目识别模块的核心损失。CRNN[5] 则提供了通用场景文本识别的另一类参考范式。

### 2.3 几何矫正与空间变换网络

空间变换网络（Spatial Transformer Networks, STN）[3]由定位网络（Localization Network）、网格生成器（Grid Generator）与可微采样器（Sampler）三部分组成，能够对输入执行可微的空间变换。由于采样坐标对变换参数可求导，识别损失能够通过反向传播间接调整几何变换，使定位网络自动学习"怎样矫正最有利于识别"。STN 并不生成新内容，只能重新组织现有像素，其作用是让识别器更容易提取稳定的序列特征。六参数仿射变换可表达平移、旋转、缩放与剪切；八参数单应变换表达能力更强，能处理近大远小与梯形畸变，但也更容易出现分母接近零、图像折叠等退化问题。

### 2.4 CCPD 数据集与评价指标

CCPD（Chinese City Parking Dataset）[13]是规模最大的中文车牌公开数据集之一，其标注信息全部编码在文件名中，包括边界框、四角点、车牌文本、倾斜角、亮度与模糊度等。CCPD2019 按场景划分为 base（普通）、db（明暗）、fn（远近）、rotate（水平旋转 10°~45°）、tilt（双向倾斜 10°~60°）、weather（天气）、blur（模糊）与 challenge（困难）等子集。识别评价采用**整牌准确率**（预测文本与真值完全一致的比例）与**字符错误率 CER**（总编辑距离除以总真值字符数）；检测评价采用 mAP@0.5；端到端评价要求检测框与真值框按 IoU 阈值匹配且整牌文本正确。

## 三、模型和算法

### 3.1 系统总体架构

系统采用模块化级联架构，数据依次流经检测、矫正、识别三个模块：

```
输入图像 → YOLOv8n 检测（边界框） → 裁剪 → STN 矫正（仿射/透视） → LPRNet + CTC → 车牌文本
```

各模块保留独立调用接口，便于建立无 STN 基线、替换几何模型与定位错误来源。核心训练范围为 STN 与 LPRNet 的可微联合优化，检测器独立训练并固定；推理时以检测器输出的预测框替换训练时使用的真值框。

### 3.2 检测模块：YOLOv8n

检测采用 YOLOv8n 轻量级基线[10]，单类"plate"，输入分辨率 416×416。其推理流程为：

1. **输入预处理**：将整张场景图像按保持宽高比的方式缩放到 416×416，不足部分补边；
2. **主干特征提取（Backbone）**：通过多层 C2f 卷积模块逐步下采样，提取不同尺度的图像特征；
3. **颈部特征融合（Neck）**：采用 FPN + PAN 结构对多尺度特征进行自顶向下与自底向上的双向融合，增强小目标与多尺度目标的表征；
4. **解耦检测头（Head）**：对每个特征图分别预测目标类别与边界框回归量；
5. **后处理**：按置信度阈值筛选候选框，再经非极大值抑制（NMS）去除重复框，输出最终的车牌边界框与置信度。

训练数据由 CCPD 文件名中的边界框转换而来，采用标准 YOLO 格式（类别 id + 归一化中心坐标与宽高）。车牌属于目标较大、纹理清晰的简单检测任务，YOLOv8n 用少量数据即可快速收敛到高精度（见 4.4 节）。

### 3.3 矫正模块：STN 与有界残差参数化

STN 对裁剪后的车牌区域（188×48）执行可微几何矫正，输出固定尺寸（94×24）的矫正图，具体分四步：

**（1）定位网络回归变换参数。** 定位网络由三层卷积（通道数 16/32/64，每层后接 2×2 最大池化）+ 自适应平均池化 + 两层全连接（隐藏维 64）组成。它接受 188×48 的车牌图，经三次下采样得到 64×6×23 的特征图，自适应池化到 2×4 后展平成 512 维特征，再经全连接回归出 6 个仿射参数（或 8 个透视参数）。

**（2）有界残差参数化。** 为保证训练的数值稳定，本项目提出并实现了有界残差参数化：

```
theta = identity + tanh(raw − identity) ⊙ bound
```

即定位网络输出 raw，实际使用的变换参数为恒等参数加上经 tanh 压缩、按分量限幅的残差。这一设计带来两点关键收益：

1. **训练起点严格等于恒等变换**：定位网络输出层权重初始化为零、偏置初始化为恒等参数，训练初期近似原图采样，避免随机采样破坏识别输入。
2. **从构造上杜绝几何塌缩**：无论梯度如何变化，变换参数都不可能被推到塌缩区（如横向放大 2.5 倍、65% 采样点越界），从而解决了仿射模式无约束训练时的塌缩问题与透视模式的分母死锁问题（详见 4.7 节）。

仿射模式的残差限幅设置为：线性部分非对角项 ±0.80（允许约 ±53° 旋转）、对角项 ±0.35、平移 ±0.30；透视模式额外将分母项限幅在 ±0.25，保证分母始终接近 1。

**（3）网格生成。** 仿射模式使用 PyTorch 的 `affine_grid`，根据 2×3 变换矩阵为输出图的每个像素计算其在输入图上的采样坐标；透视模式手写单应变换公式 `x_s = (h11·x_t + h12·y_t + h13) / (h31·x_t + h32·y_t + 1)` 完成同样的坐标映射。这里采用从输出到输入的逆向采样。

**（4）可微采样。** 用双线性插值 `grid_sample` 按计算出的采样坐标从输入图取值，得到 94×24 的矫正图。由于采样坐标对变换参数可求导，识别损失的梯度能够一路回传到定位网络。

### 3.4 识别模块：LPRNet 与 CTC

LPRNet 采用轻量级全卷积结构[2]，将 94×24 的车牌图映射为沿水平方向排列的字符概率序列。其逐层处理流程如下表：

| 层 | 操作 | 输出 (通道, 高, 宽) |
|---|---|---|
| 输入 | — | (3, 24, 94) |
| conv1 | 3→32, k3, BN+ReLU | (32, 24, 94) |
| pool1 | 最大池化 k2 s2 | (32, 12, 47) |
| conv2 | 32→32, k3, BN+ReLU | (32, 12, 47) |
| conv3 | 32→64, k3, BN+ReLU | (64, 12, 47) |
| pool2 | 最大池化 k2 s2 | (64, 6, 23) |
| conv4 | 64→64, k3, BN+ReLU | (64, 6, 23) |
| conv5 | 64→64, k3, BN+ReLU | (64, 6, 23) |
| head | 64→70, k1 | (70, 6, 23) |

输入宽 94 经两次 2 倍下采样后变为 23，即得到 **T=23 个时间步**。随后对高度方向取平均，将 (70, 6, 23) 压缩为 (70, 23)，再转置为 CTC 所需的 (T=23, N, 70) 布局。字符表含 33 个省份简称、2 个易混字母（O/I）、24 个字母、10 个数字，共 69 个可见类别，外加 1 个 CTC blank，共 70 类，网络参数量 107,558。

训练时使用 CTC 损失：先在类别维做 `log_softmax` 得到对数概率，再用 `CTCLoss(blank=69)` 计算损失——blank 放在最后一个索引，标签补齐值 -1 需先替换为合法值（超出目标长度的位置不会被读取）。解码采用贪心策略：逐时间步取概率最大类别，先合并相邻重复、再删除 blank，得到最终车牌文本。

![图 3-2(a) LPRNet 宽度下采样与 T=23 推导](../outputs/report_figures/figure_2_10_lprnet_time_steps.png)

![图 3-2(b) CTC 对齐路径与折叠规则](../outputs/report_figures/figure_2_11_ctc_alignment.png)

### 3.5 训练策略

识别训练采用 Adam 优化器与余弦退火学习率调度。每个训练步依次执行：前向（STN 矫正 → LPRNet 输出 logits）→ 计算 CTC 损失 → 反向传播 → 梯度裁剪（上限 5.0）→ 参数更新。

为让 STN 学习到大角度矫正，训练数据增强中加入 ±45° 的随机旋转（覆盖 CCPD rotate/tilt 子集的倾斜范围），并保留亮度/对比度扰动与轻微模糊，但不做水平翻转（车牌字符有方向与顺序）。训练采用两阶段策略以稳定收敛：**第一阶段**训练无 STN 基线（off），得到成熟的 LPRNet；**第二阶段**以 off 权重初始化 LPRNet、STN 从恒等起点开始，用更低学习率联合微调。这一策略避免了从头联合训练时 STN 与 LPRNet 相互干扰导致的收敛困难。

## 四、实验结果分析

### 4.1 实验设置

- **数据**：CCPD2019 的 base 子集用于训练与基础评估；rotate（9822 张，10°~45°）、tilt（30216 张，10°~60°）子集作为挑战测试集，仅用于评估。
- **划分**：按稳定哈希将样本划分为训练/验证/测试（约 8:1:1），保证可复现。
- **指标**：整牌准确率、CER、检测 mAP@0.5、端到端准确率；模式间差异采用 McNemar 精确检验评估显著性。
- **设备**：CPU 训练与推理（Apple M3）。

### 4.2 识别基线：E1 变换类型消融

在 base 测试集（246 张）上对比无矫正（off）、仿射 STN、透视 STN 三种模式，结果如下表：

| 模式 | 参数量 | 整牌准确率 | CER | 单张耗时(ms) |
|---|---|---|---|---|
| off（无矫正） | 107,558 | 90.65% | 0.0174 | 1.58 |
| affine（仿射 STN） | 164,364 | **92.68%** | 0.0145 | 6.42 |
| perspective（透视 STN） | 164,494 | 91.46% | 0.0174 | 6.76 |

仿射 STN 较无矫正基线提升约 2 个百分点，但 McNemar 检验 p=0.36，差异在 246 样本规模下未达统计显著。这一结果提示：**在 base（多数为正放车牌）上，STN 的发挥空间有限**——正放车牌本身不需要矫正，STN 的价值应体现在倾斜/旋转场景，而非基础集。

![图 4-1(b) E1 字符错误率与失败样本数](../outputs/report_figures/figure_3_3_e1_cer_failures.png)

### 4.3 STN 在倾斜/旋转挑战子集上的收益

为验证 STN 在困难场景的价值，在 rotate 与 tilt 子集上评估旋转增强重训后的三种模式。

**rotate 子集（9822 张，水平旋转 10°~45°）**

| 模式 | 整牌准确率 | CER |
|---|---|---|
| off | 22.83% | 0.2385 |
| affine | **29.86%** | 0.2049 |
| perspective | 28.11% | 0.2142 |

**tilt 子集（30216 张，双向倾斜 10°~60°）**

| 模式 | 整牌准确率 | CER |
|---|---|---|
| off | 7.53% | 0.4354 |
| affine | **9.82%** | 0.4064 |
| perspective | 9.50% | 0.4147 |

McNemar 精确检验显示：affine 与 perspective 相对 off 的提升在两个子集上均达到 **p<0.0001**，统计极其显著。仿射 STN 在 rotate 上带来 +7.03 个百分点、在 tilt 上 +2.29 个百分点的稳定收益，perspective 分别为 +5.28 与 +1.97 个百分点。这直接回应了本项目的核心研究问题——**STN 在倾斜/旋转场景能带来稳定且显著的识别收益**。

值得注意的是，挑战子集的绝对准确率整体偏低（off 在 rotate 上仅 22.83%、tilt 上仅 7.53%），说明 LPRNet 本身对强倾斜/旋转的泛化仍是瓶颈；但 STN 带来的**相对**提升是稳定且显著的，这正是 STN 的价值所在。

### 4.4 检测结果

YOLOv8n 在 CCPD base 上训练 20 个 epoch，在验证集上的检测结果如下：

| 指标 | 数值 |
|---|---|
| mAP@0.5 | **99.5%** |
| mAP@0.5:0.95 | 74.1% |
| Precision | 99.98% |
| Recall | 100% |

车牌目标较大、纹理清晰，YOLOv8n 用少量数据（5000 张）与 20 个 epoch 即达到 99.5% 的 mAP@0.5，超过项目设定的 98% 目标，检测接近性能上限。这一结果也说明：检测环节在本任务中已不是瓶颈，系统精度主要受识别环节制约。

### 4.5 端到端结果

将检测、矫正、识别三模块串联，在 base 全量（2557 张）上评估端到端性能：

| 指标 | 数值 |
|---|---|
| 检测成功率（IoU≥0.5） | 100% |
| 检测成功条件下的识别准确率 | 93.51% |
| **端到端整牌准确率** | **93.51%** |

检测 recall 达 100%，且端到端准确率仅比真值框识别（95.07%）低约 1.6 个百分点，说明检测框质量高、几乎不损伤后续识别，三阶段级联已完整打通。这一结果也印证了报告 §3.4 中的分析：检测误差对识别的影响很小，端到端精度的上限主要由识别器决定。

### 4.6 数据扩充实验

将识别训练数据从 2557 张扩充到 10000 张（从完整 base 抽样），识别整牌准确率显著提升：

| 模型 | 2557 张训练 | 10000 张训练 | 提升 |
|---|---|---|---|
| off | 90.65% | 93.14% | +2.49% |
| affine | 92.68% | **95.07%** | +2.39% |

数据扩充不仅提升精度，还显著加速收敛：扩充后的 off 在第 8 个 epoch 验证准确率即达 41%，而小数据需要约 17 个 epoch 才达到相近水平，体现了更多训练数据带来的梯度稳定性。这一实验说明识别精度尚未饱和，加大数据规模是进一步冲高的有效路径。

### 4.7 问题分析与解决

开发过程中发现并解决了两个关键训练失效问题，这也是本项目最具分析价值的部分。

**（1）仿射 STN 的无约束塌缩。** 在只使用 CTC 损失、无几何约束的初始实现中，仿射 STN 在正式训练时定位网络学会了将车牌横向放大 2.5 倍（`theta[0,0]=2.5`），导致 65% 的采样点越界、整牌准确率恒为 0%。过拟合小样本能到 100%，说明链路本身正确，问题出在优化过程而非实现。引入有界残差参数化后，变换参数被从构造上限幅在安全区间，仿射模式准确率恢复到 92.68%。

**（2）透视 STN 的回退死锁。** 透视模式原有的"非法变换回退恒等"采用不可微的硬切换，一旦变换参数触发回退，梯度被截断，定位网络陷入"越界→回退→无梯度→继续越界"的死锁，最终 100% 样本触发回退、退化为恒等（等效于无矫正）。有界残差将分母项限幅在 ±0.25，从源头避免分母塌缩，透视模式回退率归零并恢复真实矫正。

**（3）STN 收益的数据依赖性质。** 这是本项目最重要的实验发现。在未做旋转增强的正放数据上训练的 STN，面对 rotate 子集时定位网络输出接近恒等（实测学习到的旋转角仅 ±2° 以内），仿射模式甚至比无矫正基线显著更差（20.28% vs 21.89%）。而在训练中加入 ±45° 旋转增强并放宽残差限幅后，STN 真正学会了大角度矫正，在 rotate/tilt 上取得 p<0.0001 的显著收益。这一正一负的翻转说明：**STN 的矫正能力是数据依赖的，它只能学会矫正训练中见过的畸变类型**。这一结论直接回应了 §1.1 提出的研究问题，并给出了"如何让 STN 在困难场景有效"的明确路径。

## 五、结论

### 5.1 主要结论

本项目构建了"检测—矫正—识别"三阶段车牌识别系统，并围绕 STN 矫正模块完成了系统性实验，得到以下结论：

1. **系统性能**：YOLOv8n 检测 mAP@0.5 达 99.5%，识别整牌准确率经数据扩充后达 95.07%，端到端整牌准确率 93.51%，三阶段级联完整可复现，检测环节已接近性能上限、不再构成瓶颈。
2. **STN 在困难场景显著有效**：仿射 STN 在 rotate 子集上较无矫正基线提升 +7.03 个百分点、在 tilt 上提升 +2.29 个百分点，perspective 分别为 +5.28 与 +1.97 个百分点，McNemar 检验 p<0.0001，统计极其显著。这正面回答了"STN 是否有用"的研究问题——在倾斜/旋转场景，答案是肯定的。
3. **STN 收益具有数据依赖性**：在正放数据上训练的 STN 面对大角度旋转时"躺平"（定位网络输出恒等），只有在训练中引入旋转增强后才能真正学会矫正。这一发现明确了 STN 的适用条件与训练要点，是本文最有价值的结论。
4. **有界残差参数化是稳定训练 STN 的关键**：该方法从构造上杜绝了几何塌缩，修复了仿射 0% 与透视回退死锁两个失效问题，为 STN 的工程化落地提供了可复用的方案。

### 5.2 不足与展望

1. **挑战子集的绝对精度仍偏低**：rotate/tilt 上 off 基线分别仅 22.83% 与 7.53%，STN 带来的相对收益显著但绝对精度距离实用仍有距离，说明 LPRNet 对强倾斜/旋转的泛化是瓶颈。后续可引入更强的几何增强（透视扰动、整图旋转）或混合挑战数据训练。
2. **端到端准确率距 97% 目标仍有约 3.5 个百分点差距**：识别是主要瓶颈，可进一步加大训练数据规模、延长训练轮次或引入更深的识别网络。
3. **统计与扩展实验待补全**：base 上 STN 收益（+2%）在 246 样本下未达显著，需更大测试集或困难子集才能充分体现；多种子实验、定位网络结构消融（E2）、训练策略消融（E4）等扩展实验仍有待补全到正式训练预算。
4. **检测注意力改进**：检测 mAP@0.5 已接近饱和（99.5%），CBAM 等注意力模块预期无额外收益，未单独训练。
