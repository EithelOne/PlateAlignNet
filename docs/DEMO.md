# PlateAlignNet Demo 说明

## 当前实现

Demo 贯通了单张图片的完整交互链路：图片输入、候选车牌检测、ROI 裁剪、STN 模式选择、归一化输出、车牌文本、置信度、分阶段耗时以及结果下载。

当前仓库没有数据集和模型权重，因此默认使用 `demo-heuristic` 后端：检测由蓝色或绿色区域启发式完成，无法找到候选区域时使用中央回退框；识别文本是确定性的演示占位结果；“仿射”和“透视”模式目前只执行 ROI 尺寸归一化。页面会持续显示演示后端提示，避免把占位结果误认为真实模型精度。

## 启动

```bash
python -m pip install -r requirements.txt
python scripts/run_demo.py
```

已经完成下载后也可直接运行：

```bash
python -m streamlit run ui/app.py
```

## 扩展位置

真实模型只需实现三个协议：

- `Detector.detect`：接收完整图像，返回边界框、置信度和车牌类型；
- `Rectifier.rectify`：接收车牌 ROI、变换模式和输出尺寸，返回矫正图；
- `Recognizer.recognize`：接收车牌图，返回文本和置信度。

实现后在 `src/inference/factory.py` 注册新的后端。界面、异常状态、阶段耗时、结构化结果和下载功能均可继续复用。

后续功能已在界面侧边栏和标签页预留：视频/摄像头、批量推理、三种 STN 模式并排消融、历史记录、CSV 导出、错误案例画廊和实验统计。

## 分阶段开发与验收清单

以下步骤按依赖关系排列。每一步完成后先由负责人演示代码、界面或实验结果，再由全体小组成员检查；所有成员无异议后，该步骤才标记为通过并进入下一阶段。

1. **完成界面设计与功能入口预留。** 完成单张图片上传、检测结果、原始 ROI、矫正结果、车牌文本、置信度、阶段耗时和结果下载的页面设计；为视频/摄像头、批量识别、STN 消融、历史记录和实验统计保留入口。检查不同电脑分辨率下是否能完整显示，所有小组成员无异议后通过。
2. **完成数据解析与数据清单。** 实现 CCPD 文件名解析、车牌文本映射、边界框与四角点读取、异常样本记录，以及训练集、验证集和测试集清单生成。随机抽样可视化标注并由成员交叉核对，确认数据划分和字符表后通过。
3. **完成 YOLOv8 车牌检测基线。** 完成检测数据转换、训练配置、训练入口和推理适配器，输出边界框、检测置信度和车牌类型。保存配置、日志、权重与验证指标，确认能通过统一推理接口替换演示检测器后通过。
4. **完成 LPRNet 识别基线。** 实现字符表、标签编码、CTC 损失、贪心解码、训练与评估流程；先在少量样本上验证可以过拟合，再开展正式训练。确认七位和八位车牌、重复字符及空输出处理正确后通过。
5. **完成仿射 STN 矫正模块。** 实现定位网络、恒等初始化、仿射网格和可微采样，验证变换方向、坐标范围和 `align_corners` 配置。接入统一 `Rectifier` 接口并展示矫正前后结果，确认关闭 STN 时基线行为不变后通过。
6. **完成透视 STN 与稳定性保护。** 实现八参数透视变换、分母安全约束、越界统计和非法变换回退；保留与仿射模式相同的输入输出契约。使用合成倾斜样例和真实样例检查黑边、折叠及内容丢失问题后通过。
7. **完成检测、矫正、识别的系统集成。** 将真实 YOLOv8、STN 和 LPRNet 注册到推理工厂，统一返回检测框、原始 ROI、矫正图、文本、置信度、错误状态和分阶段耗时。验证无车牌、损坏图片、多车牌和模型缺失等异常流程后通过。
8. **完成核心消融实验与统一评估。** 优先完成无 STN、仿射 STN、透视 STN以及不同训练策略的比较，再根据资源执行定位网络结构、插入位置、辅助损失和检测改进实验。所有实验使用冻结的数据划分、指标脚本和配置记录，结果经小组复核后通过。
9. **完成演示增强功能。** 根据课程进度实现批量图片、视频或摄像头输入、识别历史、CSV 导出、三种 STN 模式并排展示和错误案例画廊。功能按优先级逐项验收，不影响已经稳定的单图主流程。
10. **完成最终验收与材料归档。** 在答辩电脑上重新执行冻结模型评测和演示，核对报告数值与结果文件，归档代码版本、环境、配置、日志、权重摘要、典型案例和使用说明。全体成员确认可复现、可演示且文档与实现一致后完成项目。
